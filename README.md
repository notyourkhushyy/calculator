## ▶️ run it yourself

Clone the repository:

```bash
git clone https://github.com/notyourkhushyy/calculator.git
```

Move into the project:

```bash
cd calculator
```

Compile:

```bash
gcc calculator_V1.c -o calculator
```

Run:

```bash
./calculator
```

> Windows users can run `calculator.exe` after compilation.
